# Useful Prompts for Paper Reading

提升论文阅读效率的AI提示词

## 引言

随着AI技术的发展，使用ChatGPT、Claude等AI工具辅助论文阅读已成为提升科研效率的重要方法。本文整理了一系列实用的论文阅读提示词，帮助你更高效地理解和分析学术论文。

## 一、快速理解论文

### 1. 论文概述
```
请用简洁的语言总结这篇论文的主要贡献，包括：
1. 研究问题是什么？
2. 提出了什么方法？
3. 主要结果和结论是什么？
```

### 2. 背景知识
```
请解释这篇论文中提到的以下概念：
- [具体概念]
请用通俗易懂的语言解释，适合非专业背景的读者理解。
```

### 3. 创新点提取
```
请分析这篇论文的主要创新点，包括：
1. 方法创新
2. 理论创新
3. 应用创新
4. 与现有工作的区别
```
### 4. 相关工作总结
```
请罗列本文提到的相关工作，每个相关工作提取
1. 发表时间
2. 论文标题
3. 作者
4. 会议/期刊
5. 主要贡献
6. 与本文相比局限性
```

## 二、深度分析论文

### 1. 方法论分析
```
请详细分析论文中使用的方法：
1. 方法的核心原理是什么？
2. 为什么要选择这种方法？
3. 方法的优缺点是什么？
4. 有哪些潜在改进空间？
```

### 2. 实验分析
```
请分析论文中的实验设计：
1. 使用了哪些数据集？
2. 选择了哪些基线方法？
3. 评估指标是否合理？
4. 实验结果是否充分支持论文结论？
```

### 3. 局限性分析
```
请指出论文的潜在局限性：
1. 方法层面的局限
2. 实验层面的局限
3. 假设条件的局限
4. 应用场景的局限
```

## 三、批判性思考

### 1. 质疑与挑战
```
请从以下角度提出对论文的质疑：
1. 方法是否真的有效？是否有其他解释？
2. 实验设计是否存在问题？
3. 结论是否被过度推广？
4. 是否存在我没有注意到的弱点？
```

### 2. 相关工作对比
```
请将这篇论文与以下论文进行对比：
- [论文A]
- [论文B]
分析它们的异同、优劣势，以及各自适用的场景。
```

### 3. 复现可能性
```
请评估这篇论文的可复现性：
1. 论文是否提供了足够的实现细节？
2. 代码和模型是否开源？
3. 超参数设置是否明确？
4. 复现的主要障碍是什么？
```

## 四、学习与应用

### 1. 代码实现指导
```
请提供这篇论文核心算法的伪代码或实现步骤，
重点说明关键步骤和需要注意的细节。
```

### 2. 论文写作参考
```
请分析这篇论文的结构和写作风格：
1. 引言部分的写作逻辑
2. 相关工作如何组织
3. 方法部分如何描述
4. 实验部分如何呈现结果
```

### 3. 进一步阅读
```
基于这篇论文，请推荐：
1. 相关的经典论文
2. 最新的跟进工作
3. 该领域的重要综述文章
```

## 五、特定场景提示词

### 1. 快速筛选论文
```
请在5句话内总结这篇论文的核心内容，
并给出0-10的可读性评分和理由。
```

### 2. 准备论文汇报
```
请为这篇论文准备一个15分钟的汇报PPT大纲，
包括：背景、方法、实验、结论、讨论。
```

### 3. 写文献综述
```
请帮我整理这篇论文在文献综述中应该如何定位：
1. 它解决了什么问题？
2. 它与[主题]领域的关系是什么？
3. 它为后续研究奠定了什么基础？
```

### 4. 审稿意见
```
请从审稿人的角度分析这篇论文：
1. 主要贡献是否足够新颖？
2. 技术深度是否足够？
3. 实验是否充分？
4. 写作是否清晰？
5. 给出具体的修改建议。
```

## 六、提示词使用技巧

### 1. 迭代优化
- 从宽泛的问题开始
- 根据回答逐步深入
- 要求AI提供具体的例子
- 让AI解释专业术语

### 2. 指定角色
```
作为一位[领域]专家，请分析这篇论文...
```
指定角色可以获得更专业的回答。

### 3. 要求结构化输出
```
请以以下格式回答：
- 优点：
- 缺点：
- 改进建议：
```

### 4. 多角度询问
```
请从以下几个角度分析：
1. 理论角度
2. 实践角度
3. 产业应用角度
```

## 七、注意事项

### 1. 保持批判性思维
- AI的回答仅供参考
- 重要结论需要追溯原始论文
- AI可能会产生幻觉（hallucination）

### 2. 隐私保护
- 不要上传未公开发布的论文
- 敏感研究内容需要脱敏处理

### 3. 合理使用
- AI是辅助工具，不能替代独立思考
- 建议先自己阅读，再使用AI辅助理解

## 总结

使用AI辅助论文阅读可以显著提升效率，但需要掌握正确的方法和提示词技巧。希望本文提供的提示词能帮助你更好地理解和分析学术论文。
