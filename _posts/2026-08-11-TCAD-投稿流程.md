# TCAD 投稿流程
初始提交的时间是2025年3月20日。

过了半年（2025年9月12日）返回了大修。说是如果返修之后还是得到大修，那么会直接reject，压力超大。返修提交的内容有：
1. Main Manuscript: 修改后的论文pdf文件，以及Latex源码的zip压缩包。zip压缩包只保留所需文件，不要放多余的文件。另外，在引用文献列表之后要加上各个作者的照片和简介。我第一次提交隔天就被打回来说没有author photos and bios。而且加了照片简介后，论文整个篇幅不能超14页，我又花了一周调篇幅。
2. Author Response: 一个pdf文件，对各个审稿人提出的问题逐一回答。回答前要感谢审稿人，然后解释、说明如何修改，回答后也要感谢审稿人。
3. Author's Tracked Changes: 修改后的论文pdf文件，里面用不同颜色标注出修改的内容，一个颜色对应一个审稿人的问题。
4. Supplementary Material for Review: 论文附录
5. Image: 打包论文的所有图像文件。

又过了2个月（2025年12月5日），发现ScholarOne的系统里变成Awaiting AE Recommendation，然后再过一周就收到邮件说accept，（谢天谢地谢谢小红书的接accept）。
Accept了之后还要最后提交Final Files，系统上只有 Main Manuscript需要提交，但是Author guideline里列了好多东西。这些东西我就都放在zip压缩包里了。
Author guideline里要求的文件有：
1. A softcopy of the manuscript：论文最终的pdf。这个时候不能改作者不能改引用文献。但是可以挂论文的funding信息，需要单独找各个合作导师确认一下需要挂哪些项目。
2. A file of all figures and tables without captions: pdf文件，列出论文里的table和figure列表。
3. A list of all figure and table captions in proper style for the typesetter: 一个pdf文件，放所有的table和figures。我是在overleaf里建一个新的tex，把第2项和第3项都放进去，然后编译出来再切割。
4. Softcopies of all figures, one file per figure: 把所有figure都放在一个文件夹里。
5. Brief technical biography and photo (tiff file) of each Author: 作者照片（转成tiff格式，用格式工厂就可以）。建一个txt文件，把作者简介写进去。

提交上去之后，系统还提示要完成Publication Agreement：确认论文名称、作者列表、是否满18岁能签署、同意条款、选择发表类型（把版权转给IEEE还是open access，选open access要收更多钱）、是否属于英国大学或一些项目（一般不是）、是否由皇室/欧洲议会/美国政府资助（一般不是）、签名同意发表（输入自己名字）。
隔天发邮件要求各个作者确认，需要提醒合作导师登录确认。

2025.12.09:
